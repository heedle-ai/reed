# reed

A fresh browser for every browsing agent step: Chromium in a new Podman container, allowed to reach only the hosts its program names, recording what it saw. Part of [heedle-ai](https://github.com/heedle-ai).

```lisp
(browse "https://shop.example/pricing" "cdn.shop.example")
```

Documentation is in the [wiki](https://github.com/heedle-ai/reed/wiki) (source: `docs/wiki/`).
