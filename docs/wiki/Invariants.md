Every invariant below is guarded by a test or a CI step, and CI checks this page against the code on every push with `bash .github/invariants.sh`. Only the **Guarded by** column counts. Each test named there must exist in exactly one package and is run, and the gate fails if it fails or skips; each `ci:NAME` must be a step in exactly one workflow in `.github/workflows/`. Every `TestLaw_*`, `TestInv_*` and `Fuzz*` test must be listed, and no test file may have build tags, which would hide tests from CI. A mistake isn't fixed until it has a row on this page.

Tests that need Podman (`TestContainer_*`) skip where it isn't installed, so they're guarded by `ci:containers`: the CI step that runs them on Linux with `REED_REQUIRE_PODMAN=1` and a browser image built from the runner's Chrome, and fails if any skip.
